# Clean Car | site institucional

Site one-page da **Clean Car Estacionamento e Lava-Jato**, no Centro de Caratinga - MG.

## Estrutura

```
index.html   # página única (hero, sobre, serviços, faixa, depoimentos, localização, dúvidas)
styles.css   # estilos; tema claro e escuro automático (prefers-color-scheme), acento azul cobalto
script.js    # cabeçalho via IntersectionObserver, menu mobile, animações de entrada, FAQ
assets/      # fotos e favicon
```

Sem build: HTML, CSS e JS puros. Ícones: Phosphor (CDN jsDelivr). Fontes: Geist e Geist Mono (Google Fonts).
Publique a pasta em GitHub Pages, Netlify, Vercel ou hospedagem comum.

## Antes de publicar

- **Logo**: o cabeçalho usa a marca em texto. Coloque a logo oficial em `assets/` e troque no header e no footer.
- **Depoimentos** são exemplos. Substitua por avaliações reais de clientes.
- **Horário**: só o de sábado (8h às 12h) foi informado. Complete os demais dias.
- **Instagram**: o perfil aparece cortado no print (`clean_car_carat...`). Informe o @ completo para adicionar o link.
